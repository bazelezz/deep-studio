# DEEP · «В новом свете»

Локальный прототип персонального сайта разработчика. Название DEEP временное. Публикация, платные сервисы, аналитика и передача заявок не подключены.

## Первый экран: ноутбук открывает сайт

Сначала виден тёмный фон и закрытый ноутбук. Внешней шапки и заголовка нет; остаётся небольшое действие пропуска. После открытия на дисплее появляется настоящий HTML-сайт, затем автоматически за 1,65 секунды разворачивается во всё окно. Этот же DOM становится обычным первым экраном страницы, Canvas размонтируется. Во время вступления сцена занимает всё окно, а прокрутка колесом, жестами и клавишами заблокирована. После завершения возвращается обычная нативная прокрутка без дополнительной sticky-зоны.

Фронтальная камера с FOV 18° наклонена на 18° и направлена точно по нормали открытого дисплея. Размещение рассчитывается по границам геометрии (`scene/cinematicCamera.ts`). Корпус не вращается и не перемещается. Процедурная модель имеет сужающийся алюминиевый корпус, фаски, выемку для открытия, вогнутые клавиши с печатью по поверхности, утопленный трекпад с узким физическим зазором, скруглённый LCD, тонкую рамку с прокладкой и задний шарнир. Студийное окружение и микрошероховатость генерируются локально.

`DisplaySite.tsx` — серверно отрисованный HTML с интерактивным мобильным меню. Положение рассчитывается по четырём углам дисплея с помощью проективной CSS-матрицы (`scene/projectDisplay.ts`). При расширении камера движется по прямой без поворота, общий проективный переход для Canvas и HTML выводит рамку за края окна. Размеры и композиция того же HTML плавно адаптируются к окну. После первого корректного кадра короткий локальный блик проходит по передней фаске на 0,10–0,90 секунде; затем на 0,80–1,60 секунде проявляется грань. Крышка начинает открываться на 1,80 секунде и останавливается на 5,20 секунде. Блик создаёт отдельный узкий RectAreaLight; в готовом кадре он выключен. Используется плавная кривая с нулевой скоростью и ускорением на концах, без пружины. Яркость экрана связана с углом крышки. После паузы 0,65 секунды начинается расширение на 1,65 секунды.

Вступление запускается при каждом обновлении страницы. «Повторить вступление» возвращает сцену на всё окно независимо от текущего положения страницы. Прокрутка не пропускает сцену; явная кнопка пропуска и Escape открывают сайт сразу. Пока сцена активна, остальной контент недоступен для фокуса. После завершения, пропуска или ошибки восстанавливаются стили страницы, фокусируемость контента и прокрутка. Если страница открыта с якорем, переход к нему выполняется после вступления. При reduced-motion, ошибке WebGL или подготовке дольше 3 секунд сразу доступен полноэкранный сайт без блокировки.

Блик и полностью проявленная грань должны быть отрисованы перед продолжением таймлайна: две короткие паузы снимаются после реального кадра, а не по таймеру загрузки. Это не даёт пропустить световые этапы при медленном WebGL. Анимированная сцена использует стабильный DPR 1 с первого кадра, без очистки Canvas при смене разрешения в середине открытия; зафиксированные проверочные состояния используют DPR 1,5.

Для проверки промежуточных состояний: `?scene=closed`, `?scene=glint` (локальный блик), `?scene=edge` (свет на закрытом корпусе), `?scene=gap` (первые 8,6°), `?scene=half`, `?scene=ready`, `?scene=entering` (середина расширения), `?scene=poster` (сайт без WebGL). В зафиксированном состоянии выйти на страницу можно клавишей Escape. Снимки и запись этой итерации сохраняются в `docs/screenshots/spotlight-*`. Старые `atelier-*`, `cinematic-*` и `immersive-*` относятся к предыдущим постановкам. FPS и Lighthouse не измерялись.

## Запуск

Нужен Node.js 22.9+ (проект проверяется на Node.js 24).

```powershell
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Для production:

```powershell
npm run build
npm start
```

## Контент

Все бизнес-данные находятся в `src/config/site.ts`: название, описание, композиция экрана, услуги, цены, сроки, проекты и контакты. Инструкция и поля для заполнения — в `docs/CONTENT.md`.

Логотип DEEP — самостоятельный знак «Проём» из двух встречных плоскостей и небольшая типографическая подпись. Векторные контуры находятся в `src/config/brandArtwork.json`; `BrandLogo.tsx` вставляет их прямо в HTML на дисплее, в шапке и в подвале. В `public/brand/` сохранены SVG, светлый и тёмный прозрачные PNG логотипа (2400×960), отдельного знака (1024×1024), а также презентационный PNG (1920×1080). Команда `node scripts/export-brand.mjs` повторно экспортирует файлы и favicon из единого источника. При смене имени в конфигурации логотип автоматически заменяется новым текстом.

Без `contact.endpoint` форма только копирует заявку; автоматической отправки нет. Реальные email, Telegram и соцсети скрыты до заполнения. Стоимость не задана: показывается «По запросу». Три известные сферы работ сопровождаются локальными демонстрационными иллюстрациями, а не скриншотами реальных сайтов.

## Устройство проекта

- `src/app/page.tsx` — серверная страница и коммерческие разделы.
- `src/app/globals.css` — палитра, типографика, композиция, адаптивность.
- `src/components/SceneExperience.tsx` — клиентская граница, состояния, проекция HTML и управление вступлением.
- `src/components/DisplaySite.tsx` — настоящий сайт внутри дисплея.
- `src/components/scene/` — процедурная модель, свет, экран и контроллер Three.js.
- `src/components/CraftStudy.tsx` — разбор структуры, характера и деталей.
- `src/components/DemoInterface.tsx` — интерактивный демонстрационный интерфейс.
- `src/components/ContactForm.tsx` — валидация, копирование и необязательная отправка.
- `public/images/` — локальные графические обложки и резервный визуал.

Шрифт Onest с кириллицей включён в зависимости и раздаётся локально. Внешние модели, CDN, iframe, внешние шрифты и тяжёлая постобработка не требуются. Ноутбук построен из геометрии; основание неподвижно, крышка вращается относительно заднего шарнира. Рендеринг запускается только при изменениях сцены и останавливается вне видимой области.

## До публикации

PNG логотипа: `public/brand/deep-logo-light.png` и `deep-logo-dark.png` (2400×960, прозрачные); отдельный плоский знак — `deep-symbol-light.png` / `deep-symbol-dark.png`. Объёмный знак из актуального первого экрана — `deep-symbol-3d.png` (2400×2400, прозрачный) и `deep-symbol-3d-dark.png` (тот же знак на тёмном фоне). Повторный экспорт: `node scripts/export-brand.mjs` и `node scripts/export-sculpture.mjs`. Второй скрипт читает текущую SVG-композицию из `DisplaySite.tsx`.

Чистый ZIP исходников в PowerShell: `./scripts/package-source.ps1 -OutputPath <полный-путь-к-архиву.zip>`. Архив включает код, ресурсы, настройки, тесты и четыре актуальных скриншота; зависимости, сборки, окружение и временные отчёты исключены.

Добавьте свои контакты и реальные материалы проектов, проверьте цены/сроки либо оставьте расчёт по запросу. Неподготовленные проекты можно скрыть через `visible: false`. Если нужна доставка форм, подключите свой endpoint и проверьте его ответы, защиту от спама и обработку данных. Настройте метаданные и домен; в `src/app/layout.tsx` намеренно включён `robots: { index: false, follow: false }` для прототипа.

Документация использованных API: [Next.js: lazy loading](https://nextjs.org/docs/app/guides/lazy-loading), [React Three Fiber: demand rendering](https://r3f.docs.pmnd.rs/advanced/scaling-performance).

## Текущая версия: визуальный фильм — 19 октября 2026

После ноутбука открывается один живой HTML-кадр со световым проёмом и типографикой. `FilmDirector.tsx` управляет внутренним параллаксом только после завершения intro; проективный слой остаётся под управлением `SceneExperience`. Загрузка, повтор, пропуск и WebGL fallback сохранены.

Дальше нативная прокрутка ведёт через `ScrollShowcase` (структура → спокойный дизайн → смелый → телефон) и `MotionStudy` (три демонстрационных сайта: лендинг, компания, особый проект → акцент «Под вашу задачу»). Внутри кадров двигаются объекты, открывается архитектурный визуал, собирается графическая сетка. Финальные шторки раскрывают индивидуальный подход. Это HTML/CSS/SVG с GSAP, а не записанное видео. При reduced-motion или выключенном JS кадры доступны последовательно без sticky-анимации.

Обычные услуги/прайс/кейс-карточки убраны из текущей страницы по запросу. Их конфигурация и исходные компоненты сохранены. `FilmEnd` раскрывает настоящую форму через нативный details; реальные контакты и endpoint по-прежнему настраиваются в `src/config/site.ts`. Без endpoint форма честно копирует заявку.

Реализм ноутбука: FOV 18° с пересчётом кадрирования, более тонкие низкие клавиши, плотные межрядные зазоры, локальные AO-карты по реальной геометрии клавиатуры и трекпада, тени PCF и отдельный мягкий контактный свет. Корпус неподвижен, крышка вращается на прежнем шарнире. Для надёжного LCD-композитинга слои Canvas, постера и HTML получили явный порядок; убраны вложенные отрицательные GPU-слои.

Проверены typecheck, eslint и production build. Браузерные проверки покрывают вступление, пропуск и повтор, проекцию 390/623/1440, отсутствие и потерю WebGL, обратную прокрутку, реальные перестроения интерфейса, три формата, reduced-motion/noJS и форму. Пять повторных ready-кадров дополнительно проверены по пикселям: текст LCD отрисовывается. Актуальные изображения — `docs/screenshots/film-final-*`, воспроизводимая съёмка — `docs/final-film-frames.mjs`. FPS/Lighthouse не измерялись. Ранние главы выше описывают историю разработки, а не текущую структуру страницы.

## Обложка и предметный свет — 19 октября 2026

Первый экран теперь прямо называет услугу: «Сайты для бизнеса», с описанием от первого лица. Вместо архитектурных плит — скульптурная версия существующего знака DEEP с построением и горизонтальным световым срезом. Композиция остаётся одним серверным HTML-узлом внутри дисплея и после перехода на весь экран. Тексты — `siteConfig.cover` в `src/config/site.ts`, вёрстка — `DisplaySite.tsx` и `DisplaySite.module.css`.

Ноутбук остаётся настоящей процедурной WebGL-моделью: отдельные фрезерованные отверстия под клавиши, мягкие градиентные софтбоксы в локальном окружении, раздельные материалы анодированного алюминия, ABS и стекла. Свет дисплея согласован с тёмной обложкой. Разрешение Canvas начинается с DPR 1.5 и при устойчиво медленных кадрах снижается до 1. Отражение стекла над живым HTML исчезает при переходе в страницу.

Это интерактивный растровый WebGL-рендер, без подмены модели фотографией или заявлений о неотличимости от фото. Остальные сцены и форма сохранены. Для визуальной проверки: `node docs/cover-qa.mjs` (по умолчанию локальный порт 3000; другой адрес — через QA_BASE_URL).

### Предметные материалы и световой срез

Студийные панели переставлены в угол отражения алюминиевого основания: слева широкий мягкий блик, справа холодный отблеск. Фронтальное заполнение проявляет вогнутые клавиши и печать. Стеклянный трекпад остаётся темнее окружающего металла. Число прямых источников не увеличено; камера, шарнир и движение корпуса не изменены.

После вступления знак получает интерактивный световой срез: верхняя часть раскрывает чертёж, нижняя — готовую поверхность. Нативный ползунок под знаком работает мышью, касанием и стрелками клавиатуры; Home/End показывают два крайних состояния. Одна короткая демонстрация останавливается при первом взаимодействии. При reduced-motion знак остаётся неподвижным, ручное управление доступно. Во время вступления регулятор скрыт.
