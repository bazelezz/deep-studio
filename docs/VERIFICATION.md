# Проверка результата

16 октября 2026 года. Windows, Node.js 24.16.0, Next.js 16.4.2, React 19.3.1, React Three Fiber 9.8.2, Three.js 0.183.2, GSAP 3.15.0. Точные зависимости зафиксированы в `package-lock.json`.

## Сборка

Установка зависимостей, `npm run typecheck`, `npm run lint`, `npm run build` выполнены успешно. ESLint не выдаёт предупреждений. Главная страница предварительно рендерится в HTML. Production-сервер проверен на `http://127.0.0.1:3000`.

## Браузерные сценарии

Итоговый запуск после переработки «Ночная студия» на production-сборке: **25 проверок прошли за 44,3 секунды**. Проверки типов, lint и production build повторно завершены успешно. Набор Playwright выполняется в отдельном headless Google Chrome без пользовательского профиля:

- Доступность всех разделов, отсутствие выдуманных цен и пустых ссылок.
- Два характера демонстрации, изменение колонок/типографики/палитры, настоящий переход к компоновке телефона.
- Клавиатура, три формата услуг, переход к форме с выбранным форматом.
- Валидация имени, контактов, описания задачи и перевод фокуса к ошибке.
- Реальное копирование через Clipboard API и чтение результата в изолированном Chrome. Дополнительно воспроизводимые тесты успеха и запрета API, включая резервное выделяемое поле.
- Мобильное меню, Escape, возвращение фокуса и переход к контактам.
- Ширины 375, 390, 768, 1440 и 1920 px: проверены горизонтальное переполнение и границы заголовков.
- Серверное содержимое и нативное меню при отключённом JavaScript.
- Пропуск вступления и отсутствие повторного открытия в той же сессии.
- Рост реальной проекции дисплея, передача в HTML и обратная прокрутка.
- Потеря WebGL-контекста: статичный визуал и сохранение высоты раздела.
- Отсутствие WebGL, запрещённый sessionStorage, задержка шрифтов более 4 секунд: полноценная страница без позднего запуска вступления.
- Смена reduced-motion во время приближения, быстрое нажатие якоря, изменение размера окна и возврат наверх.
- Включение и выключение reduced-motion после перехода в fallback: статичный HTML остаётся видимым, Canvas отсутствует, высота раздела сохраняется.

Тесты: `tests/interactions.spec.ts`, `tests/scene.spec.ts`. Запуск при работающем сервере: `npm run test:e2e`. По умолчанию используется установленный Google Chrome; адрес можно поменять через `PLAYWRIGHT_BASE_URL`.

## Визуальный проход

Актуальная версия первого экрана — «Ночная студия». Её диагностика, новая геометрия, студийное освещение и визуальные проверки 1440×900, 623×844 и 390×844 описаны в [NIGHT-STUDIO.md](NIGHT-STUDIO.md). Итоговые кадры имеют префикс `night-`; прежние `desktop-*`, `mobile-*` и `scene-*` сохраняют историю предыдущей версии.

Просмотрены реальные desktop/mobile-скриншоты: первый экран, весь статичный вариант страницы, демонстрации обоих характеров, услуги, проекты, форма, закрытая/частично/полностью открытая крышка, приближение и передача в HTML. Снимки находятся в `docs/screenshots/`.

После просмотра исправлены перспектива и обрезание основания, чрезмерно яркий металл, отступы первого экрана, поля телефона, расхождение baseline текста Canvas/HTML, направление градиента, мобильное совмещение, высота fallback и зоны нажатия. Переход использует одинаковый шрифт, тексты и координаты композиции; DOM размещается по вычисленной проекции дисплея.

`desktop-full.png` и `mobile-full.png` показывают полный статичный резервный вариант: обычный длинный скриншот не может одновременно показать начальное и конечное состояния одной sticky-сцены. Отдельные `scene-*.png` фиксируют её этапы. Скрипт повторного захвата основных изображений: `node tests/visual-capture.mjs`.

## Что не проверялось

Не измерялись FPS и Lighthouse, не проводилась проверка на физических телефонах, Safari и Firefox. WebGL-тесты выполнялись с программным рендерером Chrome; это не оценка производительности реальных GPU. Реальный endpoint отправки и контакты отсутствуют: форма работает в режиме копирования, доставка сообщений не заявляется.

В development-консоли Three.js может сообщать об устаревшем `Clock`, который использует React Three Fiber. Это предупреждение зависимости, не ошибка работы сцены. Намеренное отключение WebGL в тесте также вызывает диагностическое сообщение драйвера; после него срабатывает резервный режим.

Проект не опубликован. Перед публикацией нужно добавить данные владельца и реальные материалы проектов согласно `CONTENT.md`.
